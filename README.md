Um catálogo de filmes desenvolvido como projeto de estudo em Desenvolvimento Web, utilizando HTML, CSS e JavaScript.
O projeto apresenta diferentes categorias de filmes em uma interface simples, moderna e responsiva, com elementos interativos desenvolvidos em JavaScript.

<h3>Sobre o projeto</h3>

O objetivo do projeto foi desenvolver uma página web estática capaz de apresentar um catálogo de conteúdos de entretenimento que estavam em destaque no ano de 2025 de forma organizada e intuitiva.

A interface conta com diferentes categorias, exibindo 5 filmes por categoria, classificados de acordo com um cálculo realizado através das notas obtidas pelos filmes por grandes plataformas do universo cinematográfico.

O cálculo para cada categoria é feito da média de avaliações entre o IMBD, o MetaCritic e o Rotten Tomatoes, estando presente também nos 'top 5', filmes do ano de 2024 que ainda encontravam-se em alta em 2025.

O projeto também foi utilizado para praticar conceitos fundamentais de desenvolvimento Front-End, como estruturação de páginas, estilização, responsividade e manipulação de elementos através do JavaScript.

<h3>Como executar</h3>

Por se tratar de um projeto desenvolvido com HTML, CSS e JavaScript, não é necessário instalar dependências para executá-lo.

Clone este repositório:

_git clone https://github.com/julianrossatto/Catalogo-5.git_

Acesse a pasta do projeto:

_cd catalogo-filmes-series_

Abra o arquivo index.html em seu navegador;

ou

Acesse https://julianrossatto.github.io/Catalogo-5/ para visualizar através do GitHub Pages.
